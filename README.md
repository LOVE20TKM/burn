# 销毁 LOVE20 生态资产，获得 BSC LOVE20 公平发射空投

基于 LOVE20 开源代码，计划在 BSC 进行 LOVE20 协议的部署与公平发射。

TKM 链 LOVE20 及子币社区的伙伴们，可以销毁代币资产，分享 BSC 链的 LOVE20 公平发射空投。

这不是资产跨链或固定比例兑换。销毁合约只负责记录每个地址的得分和空投份额，空投将在 BSC 另行发放。

## 哪些资产可以参与？

销毁合约部署时已经完成发射的 LOVE20 根币及其直接子币社区，可以使用以下四类资产参与：

- SL 流动性质押凭证：转入销毁合约并永久锁定。
- ST 加速质押凭证：转入销毁合约并永久锁定。
- 已实际领取的治理奖励代币：由合约真实销毁。
- 已实际领取的行动奖励代币：由合约真实销毁，包括协议支持的扩展行动奖励。

未领取的奖励、部署后新发射的代币和孙币不能参与。治理奖励额度按地址和轮次计算；行动奖励额度按地址、轮次和每个行动分别计算，均以实际领取的奖励为准。

## 空投份额如何计算？

1. 每个社区的权重，在销毁合约部署时一次性确定。权重只看 SL 实际锁定的流动性所对应的 LOVE20 数量，不计算 ST。
2. 每个社区的份额由四类资产平均竞争，每类基础占 25%。某类无人参与时，其份额由该社区其他有参与的类别重新分配。
3. 同一社区、同一类别内，按每个地址的销毁得分分配。越早参与，得分系数越高。
4. 销毁期间看到的是实时预估份额；全部销毁轮次结束后，份额才最终确定。

## 一个简单例子

下面的数字只是为了说明计算方式，不代表最终部署参数。

### 1. 社区权重

销毁合约部署时，三个社区的 SL 分别对应 600、300、100 个 LOVE20：

```text
总权重 = 600 + 300 + 100 = 1,000
A 社区 = 600 / 1,000 = 60%
B 社区 = 300 / 1,000 = 30%
C 社区 = 100 / 1,000 = 10%
```

无论各社区的 ST 中还锁定了多少相应社区代币，结果仍然是 60%、30%、10%，因为 ST 不参与社区权重计算。

### 2. 类别和地址得分

假设 A 社区获得全部空投池的 60%，只有 SL 和治理奖励两类有人参与：

```text
SL 类别份额     = 60% / 2 = 30%
治理奖励类别份额 = 60% / 2 = 30%
```

地址得分等于锁定或销毁数量乘以当轮得分系数。越早参与，当前轮之后剩余的销毁轮数越多，系数越高；最后一轮的系数为 1。

假设某个社区代币的最大供应量为 100 亿，销毁合约部署时已经铸造 10 亿，每轮治理和行动奖励比例合计为 0.2%。小明在倒数第 11 个销毁轮次锁定 SL，即当前轮之后还有 10 个轮次：

```text
每轮参考奖励 = (100 亿 - 10 亿) × 0.2% = 1,800 万
单轮增长基准 = 1 + 1,800 万 / 10 亿 = 1.018
小明当轮系数 = 1.018 ^ 10 ≈ 1.195
最后一轮系数 = 1.018 ^ 0 = 1
```

小明在该轮锁定 100 个 SL，小红在最后一轮锁定 200 个 SL：

```text
小明得分 = 100 × 1.195 ≈ 119.5
小红得分 = 200 × 1 = 200

小明份额 = 30% × 119.5 / (119.5 + 200) ≈ 11.22%
小红份额 = 30% × 200 / (119.5 + 200) ≈ 18.78%
```

### 3. 奖励销毁额度

假设小明某轮从行动 A 实际领取了 100 个行动奖励代币，可销毁倍数为 5：

```text
行动 A 最多可销毁 = 100 × 5 = 500
已经销毁 120 后，行动 A 剩余额度 = 500 - 120 = 380
```

每个行动的额度单独计算。如果小明同轮还从行动 B 领取了 50 个奖励代币，行动 B 会单独产生 `50 × 5 = 250` 的额度，不能与行动 A 的额度合并。仅显示但尚未领取的奖励，不会产生可销毁额度。

### 4. 最终领取数量

假设销毁结束后，小明的最终份额约为 11.22%，BSC 空投池总量是 100,000,000 个 LOVE20：

```text
小明预计获得 = 100,000,000 × 11.22% = 11,220,000 个 LOVE20
```

实际空投数量由 BSC 侧的空投准备程序根据最终份额确定，Burn 合约本身只记录份额。

## 参与前请注意

- 所有锁定和销毁都不可撤销，请确认数量后再提交。
- 每轮只能处理当前开放轮次，错过后不能补销毁，未使用额度也不会带到下一轮。
- 必须通过销毁合约提供的入口操作；直接向合约转账不会获得得分，也无法取回。
- 具体开放轮次、通过部署校验的合约地址和操作入口将在上线前公开。
