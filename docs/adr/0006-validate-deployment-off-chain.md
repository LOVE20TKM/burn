# 通过部署校验脚本验收部署地址

范围代币、显式社区名单及权重、协议依赖一致性、Factory 列表和周期参数由部署脚本自动复核，不为这些运营判断增加管理员配置或链上校验状态。社区权重的计算方法由部署者决定，脚本只按本次部署方案复核构造参数。`scoreBase`、`totalCommunityWeight` 和 Factory 成员映射由已经测试并确认字节码一致的构造逻辑派生，部署后只读取记录，不使用已经变化的链上状态重复计算，也不作为重复的部署成功条件。部署事件的字段和发出行为由合约测试覆盖，不在部署时重新解析。脚本累计可确定的静态失败并以回滚或非零退出方式 fail-closed。

空投代币无转账税、无 rebase 等行为假设，完整销毁与顺序领取流程，以及目标链最坏批量和聚合 view 的 gas 上限，无法由一次通用部署脚本可靠证明；这些项目由合约自动化测试和本次发布的目标链 fork 验收，部署者保留验收结果。任一自动检查或发布验收失败的 Burn 地址均视为无效部署，不公布、不接入前端或外部空投流程。
