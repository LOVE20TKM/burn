# 使用统一接口查询当前或最终份额

Burn 根据冻结社区权重、活跃社区、活跃类别和分池得分，分别提供地址在指定社区的份额和地址跨社区汇总份额。`accountTokenShare` 返回四类已经包含社区权重、活跃类别权重和地址分池得分比例的份额贡献、四项之和 `total` 以及 `finalized`；`accountShare` 返回跨社区总份额和相同状态。销毁期间结果是可变化的实时预览且 `finalized = false`，全部销毁轮次结束后同一结果成为最终份额且 `finalized = true`；不增加单独的最终份额接口或份额结算交易。份额以 `1e18 = 100%` 表示，所有总值均由已向下取整的明细相加；可选同链空投的当前可领取量是独立的动态剩余池状态，不改变最终份额。
