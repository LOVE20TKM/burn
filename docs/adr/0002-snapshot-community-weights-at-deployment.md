# 部署时冻结社区权重

Burn 在部署时根据各社区 SL 实际持有 LP 所代表的根币 LOVE20 数量自动计算并永久冻结社区权重：`LOVE20 储备量 * LP.balanceOf(SL) / LP.totalSupply()`，向下取整。根币社区取 LOVE20/TKM 池的 LOVE20 储备，直接子币社区取子币/LOVE20 池的 LOVE20 储备；SL 持有的全部 LP 都计入，不拆分可提取、协议手续费或直接转入部分。ST 中锁定的社区代币或 LOVE20 不计入社区权重，ST 仅作为独立销毁类别参与份额竞争。预期权重和允许偏差只由部署校验脚本检查，不进入构造参数；校验失败的 Burn 地址不公布。
