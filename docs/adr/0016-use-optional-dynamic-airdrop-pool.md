# 可选使用同链动态剩余空投池

`airdropTokenAddress` 为零时 Burn 只计算份额，具体分配由外部程序完成；非零时该地址不得等于 `scopeTokenAddress`，参与地址在份额最终确定后按“当前 Burn 余额 × 本人最终份额 ÷ 剩余未领取份额”领取 ERC20。Burn 不快照空投池，剩余份额从 `1e18` 开始并在每次成功领取后扣除该地址份额，因此后续转入只增加尚未领取地址的可分余额，已领取地址不补发；领取顺序可能产生少量最小计量单位差异，份额舍入余量、全部地址领取后的余额和之后转入的代币均永久留在 Burn。该取舍省去管理员、快照交易和固定个人额度存储，代价是个人数量只在领取时确定。
