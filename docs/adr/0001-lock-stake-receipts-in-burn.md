# 将质押凭证永久锁定在社区代币合约

Burn 将 SL 和 ST 凭证直接转入对应社区的 LOVE20Token 合约并永久保留，使底层资产继续留在原质押系统，同时让原持有人失去对应的有效治理权。LOVE20Token 没有转出任意 ERC20 的入口，也无法主动发起 Stake 退出，因此与 Burn 自持具有相同的不可逆性，并可让 `SL/ST.balanceOf(tokenAddress)` 直接表示社区历史累计永久锁定量。该余额可能包含误转或未通过 Burn 的主动转入，不能替代 Burn 状态和事件统计本次空投获得计分的锁定量。未采用 Burn 自持、独立 Vault 或外部销毁地址，因为它们会分散社区累计数据或增加合约与信任边界。
