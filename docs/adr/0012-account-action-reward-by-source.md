# 行动激励按激励来源核销

基础行动以 LOVE20Mint 和 actionId、扩展行动以已登记扩展地址作为行动激励来源，每个来源分别核销地址在指定 `round` 的实际铸造额度，销毁得分统一汇总到社区的行动激励代币销毁类别。治理和行动激励额度都可在有效轮次内分多次使用，按累计已销毁量限制，跨轮未用额度失效。仅行动激励提供批量销毁入口，可混合多个行动来源和社区，批次顶层只传一次 `round`，并采用全有或全无语义；任一条目失败则整个批次回滚，同一来源允许重复出现并顺序累计，拆分与合并结果相同，任意零数量项回滚。所有写入口都校验传入轮次当前开放，防止延迟交易按新轮次记账。SL、ST 和治理激励使用单笔明确入口。
